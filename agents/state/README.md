# Project State Files

This directory contains the per-project memory files for the RajibLabs AI Workforce.

Each file is created from `../project-state-template.md` when a new project starts.

**Format:** `<project-slug>.md`  
**Example:** `invoicer-pro.md`, `job-board.md`

These files are the **shared memory** between agents and between OpenClaw sessions. Save and paste back the relevant file to resume any project.
